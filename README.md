# JADER seasonality analysis

This repository contains Python scripts used for the manuscript:

"Seasonality in Adverse Drug Events: Time-Series Analysis of the JADER Database Using ARIMA/SARIMA and Prophet"

## Contents

- Data preparation for overall, non-vaccine, and vaccine datasets
- ARIMA/SARIMA analysis
- Prophet analysis
- Bootstrap confidence interval estimation
- Seasonality classification

## Data source

The original JADER database is publicly available from the Pharmaceuticals and Medical Devices Agency website.

Processed datasets are not included in this repository and are available from the corresponding author upon reasonable request.

## Software environment

Python versions and package versions are described in each script.

Main packages include:

- pandas
- numpy
- statsmodels
- scikit-learn
- prophet
- matplotlib
