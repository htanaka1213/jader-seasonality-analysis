# JADER adverse-event seasonality — reproducibility code package

**Scientific Reports revised analysis, 2026-11.** This ZIP is intended to be uploaded as one GitHub release asset. It contains scripts, explanatory notes, a vaccine drug-name list, and optional historical code; it does **not** contain the original patient-level JADER REAC/DRUG records or complete model-prediction result archive.

## Getting started (local terminal or Spyder)

1. Install **Python 3.12.3** and `pip install -r requirements.txt` (a compatible CmdStan backend may also be needed for Prophet).
2. Download official PMDA JADER 2024-09 data and place unmodified REAC/DRUG files as described in `data/README_INPUTS.md`.
3. Run both scripts in `01_Data_Preparation/` to create the three `data/monthly/` files. The stratification script now loads **original CP932 DRUG directly** if a UTF-8 converted file does not exist. No manual conversion is required.
4. For a **pilot**, set `MAX_EVENTS_PER_DATASET = 1` in `02_Main_Analysis/scirep_revision_config_20261111.py`. Execute `02_Main_Analysis/run_ALL_6_REVISED_20261111_spyder.py`. Inspect outputs.
5. Set `MAX_EVENTS_PER_DATASET = None` for full analysis; run again, then run `summarize_IUT_BH_REVISED_20261111.py`. Saved output location is `outputs/main/`.
6. Set `RUN_MODE="validate"`, then `"pilot"`, then `"all"` in `03_Sensitivity_Analysis/run_full_ae_sensitivity_USER_ORIGINALS_FIXED.py`. This is *separate* from the main analysis. The script looks for inference CSVs in `data/inference/` or `outputs/main/`.
7. Use `04_Secondary_Metrics/calculate_RMSE_MAPE_revised_main.py` to read `outputs/main/` or a complete saved ZIP. It does not refit models. Run the peak-month script and S8 script separately.

## Essential analysis choices

- Data span: January 2005–December 2019; 180 months; each AE with at least 100 reports is analyzed.
- Main out-of-sample evaluation: 11 expanding-year training origins, 12 months ahead for each (2009–2019, 132 test months per AE).
- Main ARIMA: `d=1,D=0` fixed, 4 nonseasonal candidates vs 12 seasonal candidates. The seasonal model requires P+Q>0; AIC used **only among candidates with comparable likelihood contribution**.
- Primary delta MAE = MAE(nonseasonal) − MAE(seasonal). Yearwise exploratory t intervals/p values; Prophet + ARIMA/SARIMA IUT; BH correction *within dataset*.
- Model-selection sensitivity: `d=0,D=0` with intercept and `d=1,D=1`; do not directly compare AIC across differing d/D.
- RMSE/MAPE: secondary, descriptive measures calculated using *saved* monthly predictions; when any tested month has observed 0, MAPE for that entire 12-month year is unavailable.
- Peak month / peak-to-mean ratio: descriptive monthly report concentration, not seasonality proof or risk estimation.
- Supplementary Table S8: unique JADER case IDs for suspected drugs by target AE, rather than raw drug-row counts.

## Archived code is not the current inferential method

`80_Original_Submission/` contains old submitted 5-fold / legacy Prophet and ARIMA code (plus historical suspected-drug script). These codes are **not to be combined** with the revised IUT/BH results. `90_Method_Validation/` contains earlier pilot and AIC diagnostics (not primary results). The public versions have local paths configured for portability. The original unmodified files, including previous local paths, are preserved only in the **private** archive.

## Notes on reproducibility and limitations

- The public scripts have been reorganized, compiled and checked for local path references; the extraction changes were tested on synthetic DRUG encodings, but **the entire 1,476 AE analysis has not been re-run from original JADER raw records using this release bundle**.
- Existing 11-origin inference results and derived RMSE/MAPE, peak-month and sensitivity results were audited separately before release; their original numeric outputs are not changed by code packaging.
- The original user-specific full forecast ZIP and the raw JADER case-level records are **not bundled**. Replicators must prepare inputs and allow sufficient compute resources.
- Figure graphics and some table formatting were finalized separately (Excel/PowerPoint); this ZIP is the **computational code archive**, not a guarantee that all display objects are generated directly by Python.
- The yearwise t inferential intervals, overlapping training periods, low-frequency counts, and dependence structures have recognized limitations. BH-FDR q-values should be treated as exploratory within the model and testing framework.
