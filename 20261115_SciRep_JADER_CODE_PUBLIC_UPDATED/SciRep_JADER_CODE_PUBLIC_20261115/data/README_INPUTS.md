# Input data locations

No patient-level raw JADER files are included in the public release.

Place original PMDA JADER 2024-09 CSV files in `data/raw_jader/`:
- `reac202409.csv` (Shift-JIS / CP932)
- `drug202409.csv` (Shift-JIS / CP932). Optional: `drug202409_utf8.csv`.

Run both programs in `01_Data_Preparation/` to generate the following in `data/monthly/`:
- `20250112_yearly_counts_filtered.csv`
- `20260411_yearly_counts_filtered_non_vaccine.csv`
- `20260411_yearly_counts_filtered_vaccine_only.csv`

Each monthly table must contain 180 rows, covering 2005-01 through 2019-12. The original dataset creates columns for all available adverse events. The revised analysis filters by >=100 reports at runtime.

The vaccine name list is in `01_Data_Preparation/vaccine_names_extracted.csv`.

Optional `data/inference/`: three `INFERENCE_BY_METHOD_{dataset}.csv` files generated by the main analysis; sensitivity script also checks `outputs/main/`.

**No reproduction claim from raw PMDA JADER has been made for this newly repackaged public version.** The raw extraction should be verified against the archived main inputs before publication.
